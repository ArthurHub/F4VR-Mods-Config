# FullPanelSearch

The Full panel while searching: the query in the tree's header, the tree filtered to the mods and pages that match, and the page that is shown filtered to its rows that match.

- The title bar's crumbs are the page's, the last with `(filtered)` after its name.
- The tree has the mods with a match, each expanded to its pages that match, with how many on each page.
- The content is the page's rows that match, in their sections, which are open, each changed there as on the whole page, with the match underlined in its name.
- SteamVR's keyboard is shown while the field is typed in, and each key filters.

See [Search](../Search/README.md).
