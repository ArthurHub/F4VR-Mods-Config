# FullPanelSearch

The Full panel while searching: the query in the tree's header, the tree filtered to the mods and pages that match, and the results as a page.

- The title bar's crumbs are `MODS CONFIG FO4 » Search`.
- The tree has the mods with a match, each expanded to its pages that match, with how many on each page. The ray on a page shows in the help line how many of its settings match.
- The content is the settings that match, under a heading for each mod and page, each its own row, changed here as on its page.
- SteamVR's keyboard is shown while the field is typed in, and each key filters.

See [Search](../Search/README.md).
