How the menu works, with the buttons your config has.
Navigation
Open and close: Long press both thumbsticks. While the menu is minimized it shows it again.
Pointing at the menu: That hand's trigger and thumbstick work the menu, and the game does not get them: you do not fire or turn by accident.
Back: Tap the grip on either hand while pointing at the menu.
Move the menu: Long press the grip on either hand while pointing at the menu: it follows the hand until you let go.
Recenter: Long press the thumbstick on the off hand: the menu is put in front of you again. It also comes back by itself when you walk away from it.
Minimize: On the title bar: the menu is hidden as you left it, your changes too. Your offhand wrist then has Restore, which shows it again with its values read again, and Exit, which closes it.
Changes
Save: A change waits for Save, which writes it, and Discard takes it back. An MCM mod's change is made at once instead: see MCM below. Changes are kept for each mod, and leaving a mod or closing the menu with unsaved changes asks first.
Undo one change: A changed value is amber, and the undo arrow after it takes back that change alone. Discard, in the footer, takes back all of them.
Reset: Sets the mod's default, as any other change. The help line names the default.
Buttons: A button that runs a mod's script asks you to save first, as the script reads the saved values. An MCM mod's does not ask.
When a change takes effect: A mod can say it, with a mark after the row's name:
Live: The mod applies the change as you make it, so you see it in the game before you save. It is still unsaved: Save keeps it, and Discard, or leaving without saving, puts the old value back in the game too.
Save: The mod applies it when you save.
Restart: It applies after the game is restarted. The menu's front page reminds you until then.
No mark: The mod does not say, as no MCM mod does.
Marks
Amber value: Changed, not saved or kept yet.
Red value: Invalid: the help line says why.
Warning: Something to know about the value as it is: the help line says what.
Result: A button gave a result: point at its row to read it.
Greyed row: Point at it: the help line says why it cannot be changed.
MCM
MCM tag: A mod whose menu is MCM's has it after its name in the list of mods, as its changes work as below.
Keep and Revert: A change is made as you make it, as in MCM's own menu, so you see it in the game and a button's script reads it. Keep accepts it, and some mods apply it only then. Revert sets it back and runs the mod's script for it again.
Hotkeys: A mod's hotkeys are shown, not edited: change them in MCM.
A mod that is greyed: It cannot be shown: point at it to see why, and the front page lists it under Notices.
