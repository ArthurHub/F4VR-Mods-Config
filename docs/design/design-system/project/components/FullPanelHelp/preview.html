The menu doesn't pause the game, so you can see changes in the world as you make them. The controls below reflect your current button configuration.
Navigation
Open / Close: Long press both thumbsticks to open or close the menu. This also restores a minimized menu.
Point and select: Only one hand controls the menu at a time, indicated by the mark at the end of its ray. Use that hand's trigger to select and thumbstick to scroll. These inputs are blocked from the game while pointing at the menu. Point away to use the trigger in-game without accidentally selecting anything.
Back: Tap the grip on either hand while pointing at the menu to close a popup, cancel an edit, or go back one page. From Help, it returns to your previous page. From the front page, it closes the menu.
Move the menu: Long press the grip on either hand while pointing at the menu to grab it. Move your hand to reposition it, then release.
Recenter: Long press the thumbstick on the off hand to bring the menu in front of you. It also returns automatically if you move too far away.
Navigate pages: The breadcrumbs in the title bar show your current location. Select any earlier page to jump back, or MODS CONFIG FO4 to return to the front page.
Minimize: Select – in the title bar to hide the menu while inspecting changes in-game. Your current page and unsaved edits are preserved. Use Restore on your offhand wrist to bring it back and refresh its values, or Exit to close the menu (with a warning if you have unsaved changes).
Search
Search: Type in the field above the list of mods to find a setting by its name in every mod: the start of each word, in any order. The list shows the mods and pages that match, with how many.
Filtered page: A page you open while searching shows only its settings that match, with the match underlined, and (filtered) after its name in the title bar. Back shows the whole page.
Clear: Select the cross in the field, or Back while pointing at the field, to empty the search and show every mod again.
Changes
Save: Changes wait until you select Save, which writes them, or Discard, which drops them. An MCM mod applies a change at once instead: see MCM below. Each mod's changes are separate, and you're asked first when leaving a mod or closing the menu with unsaved changes.
Undo one change: A changed value turns amber. Select the undo arrow after it to undo just that change. Discard, in the footer, undoes all of them.
Reset: Sets the mod's default value, like any other change. The help line shows the default.
Buttons: A button that runs a mod's script asks you to save first, since the script reads the saved values. An MCM mod's buttons don't ask.
When a change takes effect: A mod can show it with a mark after the setting's name:
Live: The mod applies the change as you make it, so you see it in the game before saving. It is still unsaved: Save keeps it, and Discard, or leaving without saving, restores the old value in the game too.
Save: The mod applies the change when you save.
Restart: The change applies after restarting the game. The front page reminds you until then.
No mark: The mod doesn't say. MCM mods never do.
Marks
Amber value: Changed, but not saved or kept yet.
Red value: Invalid. The help line explains why.
Warning: Something to know about the current value. The help line explains it.
Result: A button returned a result. Point at its row to read it.
Greyed row: Can't be changed. Point at it and the help line explains why.
MCM
MCM tag: Shown after a mod's name in the list when its menu comes from MCM. Its changes work as described below.
Keep and Revert: Changes apply as you make them, as in MCM's own menu, so you see them in the game and a button's script reads them. Keep accepts a change, and some mods only apply it then. Revert undoes it and runs the mod's script for it again.
Hotkeys: A mod's hotkeys are shown but can't be edited here. Change them in MCM.
A mod that is greyed: It can't be shown. Point at it to see why. The front page also lists it under Notices.
Help: How the menu works, with the buttons your config has.
