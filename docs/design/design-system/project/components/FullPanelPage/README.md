# FullPanelPage

The Full panel with one of a mod's pages open instead of its front page.

**Provides:** the same as `FullPanel`, with the selected page.

- The mod's row stays expanded (down arrow) and is not selected. The page row is the selected bar, with the tip pointing at the content.
- The title bar's breadcrumbs end in the page: `MODS CONFIG VR » Immersive Flashlight VR » Beam`, the page in `green`. `»` is U+00BB, inside the font's Latin-1 range.
- The page's help is the first item of its rows, in `green-muted`, and scrolls with them.
- A name too long for its column ends in an ellipsis; the help line in the footer shows it in full while the ray is on the row.
- Back goes to the mod's front page, as the mod's crumb does.
