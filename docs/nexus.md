# Short description

A VR-first configuration menu for Fallout 4 VR mods. Access your existing MCM menus and directly configure mods like FRIK and Immersive Flashlight VR, with advanced VR controls and live preview of supported changes. All without pausing the game.

[size=4][b]Getting Started[/b][/size]
[list=1]
[*][size=3]Install the mod and its requirements.[/size][/*]
[*][size=3]In game, [b][color=#ffd966]hold both thumbsticks[/color][/b] for about one second to open the menu.[/size][/*]
[*][size=3]Point at the menu with either hand. Use the [b][color=#ffd966]trigger[/color][/b] to select and the [b][color=#ffd966]thumbstick[/color][/b] to scroll.[/size][/*]
[*][size=3]Tap [b][color=#ffd966]grip[/color][/b] to go back, or hold it while pointing at the menu to move the panel.[/size][/*]
[*][size=3]Select a mod from the list and start configuring it.[/size][/*]
[/list]

[size=3][b]Useful controls:[/b][/size]
[list]
[*][size=3][b]Recenter:[/b] Hold the offhand thumbstick to bring the menu in front of you.[/size][/*]
[*][size=3][b]Minimize:[/b] Use the – button in the title bar. Restore it from your offhand wrist without losing your place or changes.[/size][/*]
[*][size=3][b]Help:[/b] Select [color=#ffd966][b]? Help[/b][/color] in the title bar to see the current controls and tips.[/size][/*]
[/list]
[size=3]The menu takes over FRIK's existing thumbstick shortcut. You can still open FRIK's original configuration interface using Quick launch on the menu's front page.[/size]

[size=4][b]Features[/b][/size]

[b][color=#ffd966]Designed for VR[/color][/b]
[list]
[*][size=3][b]Live preview:[/b] Supported mods apply changes immediately, so you can see and feel the results in the world before saving.[/size][/*]
[*][size=3][b]VR-native controls:[/b] Sliders, switches, dropdowns, text input, color pickers, controller binding editors, haptic controls, and 3D position adjustments.[/size][/*]
[*][size=3][b]Comfortable interface:[/b] A curved panel with adjustable size, distance, height, opacity, tilt, and curvature. Customize the pointer and interactions to suit your setup.[/size][/*]
[*][size=3][b]Minimize and restore:[/b] Hide the panel to inspect your changes, then restore it from your wrist without losing your place.[/size][/*]
[/list]

[size=3][b][color=#ffd966]Native mod configuration[/color][/b]
Mods with native support can expose their settings directly in VR, including INI and TOML configuration files and Papyrus settings. No manual file editing is needed.[/size]
[list]
[*][size=3][b]Save or Discard:[/b] Changes aren't written to configuration files until you save. Discard restores the previous values, including changes already previewed in the game.[/size][/*]
[*][size=3][b]Undo and Reset:[/b] Changed settings are highlighted. Undo individual changes or restore default values.[/size][/*]
[*][size=3][b]Know when changes apply:[/b] Settings indicate whether they take effect live, on Save, or after restarting the game.[/size][/*]
[*][size=3][b]Validation:[/b] Invalid values are highlighted with an explanation, preventing accidental saves of invalid settings.[/size][/*]
[*][size=3][b]Unsaved changes protection:[/b] The menu asks before leaving a mod or closing with pending changes.[/size][/*]
[/list]

[size=3][b][color=#ffd966]Your existing MCM mods, now in VR[/color][/b]
Mods Config also displays your existing MCM menus in the same interface, without requiring mod authors to change anything.[/size][/size]
[list]
[*][size=3][size=3][b]MCM compatibility:[/b] Browse existing pages, settings, images, help text, and translations. Supported buttons and presets execute their original scripts.[/size][/size][/*]
[*][size=3][size=3][b]Keep and Revert:[/b] MCM changes take effect immediately, just as they do in MCM. Keep accepts the changes, while Revert restores the previous settings.[/size][/size][/*]
[*][size=3][size=3][b]Text input in VR:[/b] Enter text using SteamVR's keyboard, or a physical keyboard.[/size][/size][/*]
[*][size=3][size=3][b]Existing hotkeys:[/b] Hotkeys are displayed, while MCM continues to manage their bindings and execution.[/size][/size][/*]
[/list]
[size=3][size=3]
[b]MCM VR is still required for MCM-based mods.[/b] Mods Config provides the VR interface, but does not replace MCM's underlying functionality. Some MCM-specific Flash controls are not available in Mods Config; see the documentation for compatibility details.[/size]
[/size]

[size=4][b]For Mod Authors[/b][/size]

[size=3]Want your mod to support Mods Config?

[b]Existing MCM menus work without modification.[/b] For a richer configuration experience, you can add a [b]config spec[/b] — a single JSON file that describes your mod's settings, with no additional code required.

A config spec can provide:[/size][/size]
[list]
[*][size=3][size=3][b][color=#ffd966]Direct configuration:[/color][/b] Edit INI and TOML files, including files in My Games, and Papyrus globals and properties. File comments and formatting are preserved.[/size][/size][/*]
[*][size=3][size=3][b][color=#ffd966]Rich menus:[/color][/b] Nested pages, collapsible sections, conditional controls, warnings, presets, images, and more.[/size][/size][/*]
[*][size=3][size=3][b][color=#ffd966]Safe editing:[/color][/b] Save, Discard, Undo, Reset, validation, and per-setting control over when changes take effect.[/size][/size][/*]
[*][size=3][size=3][b][color=#ffd966]Live preview:[/color][/b] Preview changes to globals and properties, integrate with F4VR Common Framework automatically, or use the native API for your own DLL.[/size][/size][/*]
[*][size=3][size=3][b][color=#ffd966]Advanced VR controls:[/color][/b] Controller bindings, haptics, color pickers, and positions that can be adjusted directly in the game world.[/size][/size][/*]
[*][size=3][size=3][b][color=#ffd966]Developer tools:[/color][/b] Inspect configuration errors and warnings in VR, and edit a live copy of your config spec that reloads while the game runs.[/size][/size][/*]
[/list]
[size=3][size=3]
[b]You can keep your existing MCM menu.[/b] Ship a config spec alongside it so players using Mods Config get the richer interface, while everyone else can continue using MCM.

[b]Getting started:[/b] Download the optional [b]Showcase[/b] package for working examples of the available features, or use the [url=https://github.com/ArthurHub/F4VR-Mods-Config/blob/main/docs/for-mod-authors/ai-agent.md]AI agent prompt[/url] to generate a config spec from your existing mod.[/size]
